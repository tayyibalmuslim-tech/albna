# منهجي في طلب العلم

منصة شخصية (HTML + CSS + JavaScript فقط، بدون أي Framework) لتنظيم دراسة العلوم الشرعية ومتابعة الإنجاز، جاهزة للرفع على GitHub Pages.

## 1) شجرة الملفات

```
project/
├── index.html          الصفحة الرئيسية (المراحل + البحث + الإحصائيات)
├── style.css            التصميم الكامل
├── script.js             منطق الإنجاز، LocalStorage، البحث، التبويبات
├── data.js               بيانات كل المراحل/المواد/المحاضرات/الأيام (SITE_DATA)
│
├── stage-1/
│   ├── index.html        صفحة المرحلة الأولى (تبويب المواد + تبويب الأيام)
│   ├── nahw/
│   │   ├── index.html    صفحة المادة (قائمة المحاضرات)
│   │   └── lectures/
│   │       └── 01.html   صفحة المحاضرة (Placeholder)
│   ├── fiqh/  ... hadith/  ... quran-sciences/  ... aqeedah/
│   ├── anwar-al-anbiya/  ... riyad-al-saliheen/
│   ├── sharaya-wasael-maqasid/  ... raqaeq-al-quran/  ... mu_alajat-al-quran/
│
├── stage-2/index.html    صفحة "قريبًا"
├── stage-3/index.html    صفحة "قريبًا"
└── stage-4/index.html    صفحة "قريبًا"
```

كل بيانات المرحلة الأولى (10 مواد، 36 محاضرة، 48 يومًا) مبنية من `data.js`، ونظام الإنجاز يعتمد على **معرف فريد (id)** لكل محاضرة مثل `stage1_fiqh_03`، وليس على اسم الصفحة، لذلك تتزامن حالة الإنجاز تلقائيًا بين صفحة المادة وصفحة الأيام وصفحة المحاضرة نفسها.

## 2) كيف يعمل نظام الإنجاز؟

- عند تحديد Checkbox محاضرة، يتم حفظ الحالة في `localStorage` باستخدام مفتاح المحاضرة (`id`).
- Checkbox المادة و Checkbox المرحلة **يُحسبان تلقائيًا** (ويظهران كعنصر معطّل/Disabled يعكس النسبة) بناءً على عدد محاضرات المادة/المرحلة المكتملة.
- أيام "استدراك وراحة" و"اختبار المرحلة" لها Checkbox مستقل خاص بها فقط في تبويب "الأيام"، ولا تدخل في حساب نسبة المادة أو المرحلة.

## 3) كيف أضيف محاضرة جديدة؟

1. افتح `data.js`.
2. ابحث عن المادة المطلوبة داخل `SITE_DATA.stages.stage1.subjects`.
3. أضف كائن جديد داخل مصفوفة `lectures`، مثال:
   ```js
   { id: "stage1_fiqh_10", n: 10, day: 50, title: "عنوان المحاضرة الجديدة", file: "lectures/10.html" }
   ```
4. إذا أردت أن تظهر في تبويب "الأيام"، أضف عنصرًا مطابقًا في مصفوفة `days` الخاصة بنفس المرحلة (بنفس `lectureId`).
5. أنشئ ملف HTML جديد باتباع نفس نمط أي ملف موجود داخل `lectures/` (يمكنك نسخ ملف محاضرة موجود وتعديل العنوان والـ id).

> ملاحظة: يمكنك أيضًا تعديل ملف `gen/build.js` (المولّد) وإعادة تشغيله لإنشاء الملفات تلقائيًا بدل كتابتها يدويًا، إذا احتفظت بنسخة المولّد.

## 4) كيف أضيف مادة جديدة؟

1. أنشئ مجلدًا جديدًا داخل `stage-1/` باسم مختصر بالإنجليزية (key)، مثل `stage-1/tafsir/`.
2. أنشئ بداخله مجلد `lectures/` وملف `index.html` (انسخ نمط أي مادة موجودة وعدّل الاسم والشيخ والهاشتاجات وقائمة المحاضرات).
3. أضف المادة إلى `data.js` داخل `subjects` بنفس الشكل:
   ```js
   {
     "key": "tafsir",
     "name": "اسم المادة",
     "sheikh": "اسم الشيخ",
     "tags": ["علم_شرعي"],
     "lectures": [ ... ]
   }
   ```
4. أضف بطاقة المادة في `stage-1/index.html` (أو اترك الأمر لـ `script.js`، فهو يبني قائمة المواد تلقائيًا من `data.js` — لا حاجة لتعديل يدوي في صفحة المرحلة).

## 5) كيف أستبدل صفحة محاضرة فارغة بمحتوى حقيقي؟

افتح ملف المحاضرة مثل `stage-1/fiqh/lectures/03.html`، وابحث عن القسم:

```html
<div class="lecture-placeholder">
  <p>سيتم إضافة المحاضرة هنا لاحقًا</p>
  ...
</div>
```

استبدله بما تريد (رابط يوتيوب مضمّن iframe، مشغل صوت `<audio>`، رابط PDF، نص المحاضرة، ملاحظاتك...) دون الحاجة لتعديل أي ملف آخر في المشروع — Checkbox الإنجاز وBreadcrumbs في نفس الصفحة يستمران في العمل كما هما.

## 6) كيف أضيف المرحلة الثانية لاحقًا؟

1. في `data.js`، أضف كائنًا جديدًا داخل `SITE_DATA.stages` باسم `stage2` بنفس بنية `stage1` (subjects + days).
2. أنشئ مجلد `stage-2/` بنفس تنظيم `stage-1/` (مجلد لكل مادة، ومجلد `lectures/` داخل كل مادة).
3. أنشئ `stage-2/index.html` بنفس نمط `stage-1/index.html` (انسخه وغيّر `data-stage-id="stage2"` وروابط الـ breadcrumbs).
4. لا حاجة لتعديل الصفحة الرئيسية (`index.html`) أو `script.js` — بمجرد وجود `SITE_DATA.stages.stage2`، ستظهر بطاقة المرحلة الثانية تلقائيًا بإحصائياتها الحقيقية بدل حالة "قريبًا".

## 7) الرفع على GitHub Pages

كل الروابط في المشروع نسبية (Relative Paths)، لذلك يكفي رفع محتويات مجلد `project/` كما هي إلى مستودع GitHub، ثم تفعيل GitHub Pages من إعدادات المستودع (Settings → Pages → Branch)، وسيعمل المشروع مباشرة دون أي إعداد إضافي.
